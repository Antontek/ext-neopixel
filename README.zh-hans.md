# LED 灯条（WS2812 / NeoPixel）

全彩 LED 灯条，每颗灯可以设置不同颜色。使用 MicroPython 内置的 `neopixel` 模块，不需要另外上传库。

## 接线

| 灯条 | 开发板 |
|---|---|
| 5V | 5V（VBUS）；灯很多时要另外接电源 |
| GND | GND |
| DIN | 积木上设置的引脚（默认 GP16） |

## 积木

1. **LED 灯条 引脚 … 共 … 颗**：放在程序最前面，设置一次。
2. **把第 … 颗设成 …**、**全部设成 …**：设置颜色（第一颗是 0）。
3. **更新灯条**：设置完颜色后要更新，灯才会亮。
