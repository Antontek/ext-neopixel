# LED 燈條（WS2812 / NeoPixel）

全彩 LED 燈條，每顆燈可以設定不同顏色。用 MicroPython 內建的 `neopixel` 模組，不用另外上傳函式庫。

## 接線

| 燈條 | 板子 |
|---|---|
| 5V | 5V（VBUS）；燈很多時要另外接電源 |
| GND | GND |
| DIN | 積木上設定的腳位（預設 GP16） |

## 積木

1. **LED 燈條 腳位 … 共 … 顆**：放在程式最前面，設定一次。
2. **把第 … 顆設成 …**、**全部設成 …**：設定顏色（第一顆是 0）。
3. **更新燈條**：設定完顏色後要更新，燈才會亮。
