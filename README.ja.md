# LED テープ（WS2812 / NeoPixel）

LED ごとに色を設定できるフルカラー LED テープです。MicroPython 内蔵の `neopixel` モジュールを使うので、ライブラリをアップロードする必要はありません。

## 配線

| LED テープ | ボード |
|---|---|
| 5V | 5V（VBUS）。LED が多いときは別の電源をつないでください |
| GND | GND |
| DIN | ブロックで設定したピン（初期値 GP16） |

## ブロック

1. **LED テープ ピン … LED … 個**：プログラムの最初に置いて、一度だけ設定します。
2. **… 番目の LED を … にする**、**すべての LED を … にする**：色を設定します（最初の LED は 0 番）。
3. **LED テープを更新する**：色を設定したあとに更新すると、LED が光ります。
